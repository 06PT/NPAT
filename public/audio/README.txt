Optional fallback sound: public/audio/loser.mp3
Used only when the MP4 meme video is missing or cannot load.
If your MP4 contains audio, no separate MP3 is needed.
Use MP3 audio, ideally a 1–5 second clip under 1MB.
If this file is absent too, the game plays its built-in descending sound effect.
The mute button controls both video and fallback audio.
